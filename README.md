
# CC-BeeOS
An "operating system" for Computercraft/CC:tweaked.  

<img width="1920" height="1200" alt="2026-10-22_12 14 59" src="https://github.com/user-attachments/assets/86343857-fbab-43a5-99d9-f6572f7db94c" />

BeeOS is designed to be simple, modular, and configurable.  

## Features:  
- BeeOS API which is able to replace most of the features from CraftOS' Shell API.
- Easy configuration with config files.
- Modular system which allows users to replace components such as the shell.
- Full suite of programs and command line utilities.

## Planned Features:
- BeePKG package manager.
- Desktop environments.

## Install:
- Run: "wget run https://raw.githubusercontent.com/bennybest7/CC-BeeOS/refs/heads/main/installer.lua" in CraftOS.
